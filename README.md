# <span style="color:#4CAF50;">🌟 Aadhaar OCR Scanning System</span>

A smart, fast and user-friendly **Aadhaar Scanning Web Application** that captures a photo of an Aadhaar card, reads the details automatically, and stores the data in a Google Sheet — instantly.

No app download.
No manual typing.
Just **Scan → Extract → Save.**

---

## 📸 **What This System Does**

* Opens **mobile or laptop camera**
* Takes a clear photo of an Aadhaar card
* Automatically extracts:

  * 👤 Name
  * 🎂 Date of Birth
  * 🚻 Gender
  * 🔢 Aadhaar Number
* Saves the data **directly into a Google Sheet**
* Works anywhere, anytime — just needs internet

---

## 🧠 **Why This Tool Is Useful**

✔ Reduces manual typing
✔ Avoids spelling mistakes
✔ Saves time during field surveys
✔ Works for NGOs, organizations, and ID verification systems
✔ Super fast — takes 3–5 seconds per scan

## 🛠️ **How It Works (Non-Technical)**

1. User opens the website
2. Grants camera permission
3. Points camera at Aadhaar
4. System reads all the text
5. Sends only the extracted details to a Google Sheet
6. Data appears instantly with time-stamp

## 📝 **About This Project**

This system was built to simplify Aadhaar-based data collection.
Instead of typing details manually from hundreds of Aadhaar cards, this tool completes the job in just a few seconds.

It is designed to save **time, effort, and human errors**, especially for teams working with farmers, villagers, and large events.
